I care about software that feels fast, reads clearly, and doesn't fall over at 2am.

How I work

The process

No mystery, no disappearing for three weeks.

  1. 01

    Understand

    We talk through the problem, the users, and the constraints before a line of code exists. Scope gets written down.

  2. 02

    Plan

    Data model, architecture, and milestones, including which platforms ship when. You see the shape of the thing up front.

  3. 03

    Build

    Work ships in visible increments with a live preview URL and test builds for mobile. You review as it goes.

  4. 04

    Ship & support

    Deploy, store submission, monitoring, and handover docs. I stay reachable after launch, because that is when real bugs surface.
