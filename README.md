# buidbyfahad.github.io

Personal site, served by GitHub Pages at <https://buidbyfahad.github.io>.

Plain HTML and CSS — no build step, no dependencies.

## Editing

- `index.html` — all page content
- `assets/style.css` — all styling (light/dark via `prefers-color-scheme`)

Preview locally:

    python3 -m http.server 8000

then open <http://localhost:8000>.

## Deploying

Push to `main`. GitHub Pages rebuilds automatically, usually within a minute.
